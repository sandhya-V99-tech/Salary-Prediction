About This Project

Dataset, methodology, and technical details

Project Overview

SalaryIQ is an end-to-end data science project built on a scraped Glassdoor dataset containing thousands of real job postings for data science roles across the United States.

The project covers exploratory data analysis, feature engineering, machine learning model training, and deployment as an interactive web application via Flask.

PythonFlaskscikit-learn pandasnumpyjoblib Chart.jsRandom ForestGlassdoor Dataset

Dataset

  • Scraped from Glassdoor.com job postings
  • Data science, ML, and analyst roles across the US
  • Includes company metadata, salary estimates, descriptions
  • Pre-processed with feature engineering for ML training
  • Available publicly on Kaggle

ML Model

  • Random Forest Regressor via scikit-learn
  • Target: average estimated salary in $K
  • 17 engineered features across skills, seniority, sector
  • Label encoding for all categorical variables
  • Serialized with joblib as salary_model.pkl
