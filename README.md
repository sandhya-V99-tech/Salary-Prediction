## 🚀 Step 1 — Run the Colab Notebook

1. Open [Google Colab](https://colab.research.google.com/)
2. Upload `colab/glassdoor_salary_analysis.ipynb`
3. Upload the 3 CSV files when prompted:
   - `eda_data.csv`
   - `glassdoor_jobs.csv`
   - `salary_data_cleaned.csv`
4. Run all cells (`Runtime → Run all`)
5. The last cell will **auto-download** these files:
   - ✅ `salary_model.pkl`
   - ✅ `model_features.json`
   - ✅ `dashboard_data.json`
   - ✅ Several `.png` chart images

---

## 🖥️ Step 2 — Set Up Flask Backend in VS Code

### 2a. Place the downloaded files

Copy the 3 files from Colab into the `backend/` folder:

```
backend/
├── salary_model.pkl        ← from Colab
├── model_features.json     ← from Colab
├── dashboard_data.json     ← from Colab
```

### 2b. Open terminal in VS Code

```bash
cd backend
```

### 2c. Create virtual environment (recommended)

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 2d. Install dependencies

```bash
pip install -r requirements.txt
```

### 2e. Run the Flask app

```bash
python app.py
```

You should see:
```
🚀 Starting Glassdoor Salary Predictor...
   Open: http://localhost:5000
 * Running on http://0.0.0.0:5000
```

### 2f. Open in browser

Go to → **http://localhost:5000**

## 🔌 API Endpoints

| Method | Endpoint           | Description                          |
|--------|--------------------|--------------------------------------|
| GET    | `/`                | Main dashboard & predictor UI        |
| GET    | `/api/dashboard`   | JSON stats for charts                |
| POST   | `/api/predict`     | Salary prediction (JSON body)        |
| GET    | `/api/encodings`   | Label encoding maps for dropdowns    |

### Example `/api/predict` request:

```bash
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "python_yn": 1, "R_yn": 0, "spark": 1, "aws": 1, "excel": 0,
    "Rating": 4.0, "age": 15, "desc_len": 2000, "num_comp": 3,
    "same_state": 1, "hourly": 0, "employer_provided": 0,
    "job_simp_enc": 2, "seniority_enc": 2,
    "sector_enc": 12, "size_enc": 4, "state_enc": 5
  }'
```

### Example response:

```json
{
  "predicted_salary_k": 118.4,
  "predicted_salary_usd": 118400.0
}
```

## ❓ Troubleshooting

| Problem | Fix |
|---------|-----|
| `salary_model.pkl not found` | Run Colab notebook and copy the file to `backend/` |
| `ModuleNotFoundError` | Run `pip install -r requirements.txt` in your venv |
| Charts not loading | Check browser console; make sure Flask is running |
| Port 5000 already in use | Change `port=5000` to `port=5001` in `app.py` |
